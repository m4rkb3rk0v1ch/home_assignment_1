Week 1 - History
- Cuneiform used wedge-shaped marks pressed into clay tablets to record information in ancient Mesopotamia.
- Movable type allowed printers to rearrange and reuse individual characters for different texts.
- Monospace fonts give every character the same width and are commonly used for programming.

Week 2 - Bits and Bytes
- A bit can be 0 or 1, and one byte contains 8 bits.
- Binary uses base 2, decimal uses base 10, and hexadecimal uses base 16.
- RAM is volatile and loses its contents without power; SSDs and HDDs retain stored data.

Week 3 - Text Structure
- Markdown uses symbols to format text, such as # for headings, - for bullet lists, and **text** for bold.
- HTML uses tags such as <p> for paragraphs and <li> for list items.
- Unicode assigns code points to characters; UTF-8 encodes those code points using one to four bytes.

Week 4 - Keyboards and Editors
- Text editors work with plain text, while word processors also store document formatting.
- Regular expressions search for patterns rather than only exact words.
- Keyboard shortcuts and multiple cursors can make editing text faster.

Week 5 - Command Line Interfaces
- pwd displays the current directory, ls lists its contents, and cd changes directories.
- cat displays file contents, while grep searches text for matching patterns.
- SSH provides a secure connection to a remote computer and allows command-line access.
